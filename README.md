# Сравнение методов решения СЛАУ

В проекте реализованы:

- метод Гаусса без выбора ведущего элемента;
- метод Гаусса с частичным выбором ведущего элемента;
- LU-разложение без перестановок;
- прямая и обратная подстановки;
- замер времени и проверка точности (невязка, относительная погрешность).

## Описание алгоритмов

### Метод Гаусса

Прямой ход: матрицу приводят к верхнетреугольному виду — из каждой нижней строки
вычитают ведущую, умноженную на множитель, чтобы обнулить элементы под диагональю
(правая часть `b` пересчитывается вместе с матрицей). Обратный ход
(`backward_substitution`): из полученной треугольной системы `Ux = b'` неизвестные
находят снизу вверх.

**С выбором ведущего элемента.** Перед каждым шагом в текущем столбце ищется
максимальный по модулю элемент, и его строка переставляется на место ведущей. Это
уменьшает деление на малые числа и накопление ошибок округления.

### LU-разложение

Матрицу `A` представляют в виде произведения двух треугольных: `A = L·U`, где
`L` — нижнетреугольная с единицами на главной диагонали, `U` — верхнетреугольная.
Элементы считаются по формулам:

```
U[k][j] = A[k][j] − Σ(s<k) L[k][s]·U[s][j],            j ≥ k
L[i][k] = (A[i][k] − Σ(s<k) L[i][s]·U[s][k]) / U[k][k], i > k
```

Само разложение не зависит от правой части и стоит O(n³). После него систему
`Ax = b` решают в два дешёвых шага по O(n²):

1. `Ly = b` — прямая подстановка (`forward_substitution`), сверху вниз;
2. `Ux = y` — обратная подстановка (`backward_substitution`), снизу вверх.

Поэтому при многих правых частях с одной и той же матрицей LU выгоднее метода
Гаусса: разложение выполняется один раз, а для каждой новой `b` нужны только две
подстановки. В этой реализации LU выполняется без перестановок строк, поэтому на
сильно вырожденных матрицах (например, Гильберта при n = 15) оно может не сработать.

## Запуск

Основная версия — на C (в корне репозитория). Нужен компилятор C (gcc/clang) и make:

```bash
make
./lab
```

Версия на Python лежит в папке `python/` (для запуска нужен только Python 3):

```bash
cd python
python3 main.py
```

## Структура

C-версия (в корне), Python-версия (в `python/`) — одинаковый набор модулей:

- `matrices` — генерация матриц и векторов (случайные, Гильберта) и базовые операции.
- `solvers` — методы Гаусса, LU-разложение, прямая и обратная подстановки.
- `metrics` — невязка и относительная погрешность.
- `timing` — замер времени.
- `experiments` — три эксперимента и вывод таблиц.
- `main` — точка входа, запуск экспериментов.

## Что делает программа

1. Сравнивает время решения одной системы разными методами (n = 100, 200, 500).
2. Показывает, почему LU-разложение выгодно при нескольких правых частях (k = 1, 10, 100).
3. Проверяет точность на матрицах Гильберта (n = 5, 10, 15).

Результаты выводятся в консоль в виде таблиц. Все эксперименты воспроизводимы
за счёт фиксированного seed = 42.
