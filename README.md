# Сравнение методов решения СЛАУ

Метод Гаусса и LU-разложение, сравнение по времени и точности.

В проекте реализованы:

- метод Гаусса без выбора ведущего элемента;
- метод Гаусса с частичным выбором ведущего элемента;
- LU-разложение без перестановок;
- прямая и обратная подстановки;
- замер времени и проверка точности (невязка, относительная погрешность).

## Запуск

Нужен только Python 3, сторонние библиотеки не используются.

```bash
python3 main.py
```

## Структура

- `matrices.py` — генерация матриц и векторов (случайные, Гильберта) и базовые операции.
- `solvers.py` — методы Гаусса, LU-разложение, прямая и обратная подстановки.
- `metrics.py` — невязка и относительная погрешность.
- `timing.py` — замер времени работы функции.
- `experiments.py` — три эксперимента и вывод таблиц.
- `main.py` — точка входа, запуск экспериментов.

## Что делает программа

1. Сравнивает время решения одной системы разными методами (n = 100, 200, 500).
2. Показывает, почему LU-разложение выгодно при нескольких правых частях (k = 1, 10, 100).
3. Проверяет точность на матрицах Гильберта (n = 5, 10, 15).
